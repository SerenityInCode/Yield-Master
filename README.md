# 🌾 Yield Master - Crop Recommendation System

## Overview

**Yield Master** is a machine learning-based system designed to recommend suitable crops based on soil and weather parameters. This tool helps farmers make data-driven decisions to maximize their yield.

## 📊 Dataset

The project uses the `Crop_Recommendation.csv` dataset, which contains various features such as:

- **N**: Nitrogen content in soil
- **P**: Phosphorus content
- **K**: Potassium content
- **temperature**: Temperature in °C
- **humidity**: Relative humidity in %
- **ph**: pH value of the soil
- **rainfall**: Rainfall in mm
- **label**: Recommended crop

## ⚙️ Features

- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Class distribution analysis
